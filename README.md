# ARCANA · 塔罗秘仪

一个沉浸式的塔罗牌占卜网页游戏：暗黑奇幻 × 神秘学视觉风格，完整 78 张牌、四种经典牌阵、可交互的洗牌 / 切牌 / 抽牌 / 翻牌流程，以及本地运行的中文解读引擎。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 预览生产构建
npm test           # 运行引擎单元测试
```

使用哈希路由（`#/result/...`），`dist/` 可直接部署到任何静态托管（GitHub Pages、Netlify、本地文件服务器等）。

## 功能

| 模块 | 说明 |
| --- | --- |
| 首页 | 动态星空（Canvas 星点 / 光尘 / 流星）、旋转魔法阵、漂浮牌背、主题与牌阵入口 |
| 牌库 | 22 张大阿尔卡那 + 56 张小阿尔卡那（权杖 / 圣杯 / 宝剑 / 星币）；每张牌有编号、正逆位关键词、正逆位牌义、画面象征、行动建议，以及感情 / 事业 / 学业 / 财运的正逆位解释 |
| 卡面插画 | 78 张独立的 SVG 金箔线描插画（依据 RWS 象征原创绘制，非原版插画）：大牌各自独立构图；数字牌按牌意排布花色符号并配独立场景；宫廷牌有人物、坐骑 / 王座与花色徽记 |
| 牌阵 | 单张指引、时间之流（过去 / 现在 / 未来）、爱情之镜（5 张）、凯尔特十字（10 张，第 2 张横置） |
| 抽牌流程 | 洗牌（可多次，带分叠交错动画）→ 切牌（三叠选一，真实改变牌序）→ 扇形展开 78 张牌 → 点击或上拖选牌、左右滑动 / 滚轮旋转牌扇 → 牌飞入牌阵位置 → 背景变暗 → 逐张 3D 翻牌（光环 + 粒子光效，逆位再旋转 180°）|
| 结果页 | 牌阵布局、综合结论、逐张解读（牌义 × 位置）、牌间关联、能量图谱（元素分布、灵数牌）、分领域建议，逐段淡入 |
| 用户功能 | 每日一抽（含连续天数）、收藏牌、占卜历史（星标 / 筛选 / 删除）、复制与分享、重新占卜、三套主题、逆位开关、自动翻牌、减少动效、粒子开关、数据导入 / 导出 |
| AI 解读（可选） | 结果页可调用 Claude 生成叙事式深度解读，默认关闭，需在设置中填入自己的 API Key |

所有数据保存在浏览器 LocalStorage（`arcana:v1:*`），刷新后保留。

## 解读引擎如何工作

解读不是把几张牌的含义拼在一起，而是分四层逐层综合（`src/engine/interpret/`）：

1. **位置视角**：同一张牌在「过去」「阻碍」「对方的想法」「建议」等位置有不同读法。例如一张吉牌落在阻碍位，会被解读为「过犹不及」。
2. **牌间关系**：元素尊贵（同元素加强、火风 / 水土相生、火水 / 风土相克）、相邻位置的能量轨迹，以及牌阵特有的对位（凯尔特十字的 1×2、3↔5、7↔8、9↔10；爱情牌阵的你与对方是否同频、建议如何化解阻碍）。
3. **整体能量**：大小阿尔卡那比例、主导与缺失元素、逆位比例、宫廷牌数量、数字重复、经典组合（如高塔 + 星星）、灵数牌（数字约化为一张大牌）。
4. **综合结论**：按位置加权计算能量趋势，选出关键牌，生成叙事结论与感情 / 事业 / 学业 / 财运建议，问题所属领域排在最前。

文案选择基于占卜 id 的哈希，同一次占卜每次打开都得到相同结果。

## AI 解读接口

`src/engine/ai.ts` 定义了 `InterpretationProvider` 接口，并提供基于官方 `@anthropic-ai/sdk` 的 `ClaudeProvider`：

- 默认模型 `claude-opus-5-5`，可在设置中切换 Sonnet 5.5 / Haiku 5.5
- 流式输出，结果缓存到该条占卜记录中
- 本地引擎的结构化分析会作为上下文传给模型，使 AI 解读与牌面逻辑一致
- 已启用服务端 fallback（`fallbacks: "default"`）：若模型的安全分类器拒绝请求，会自动改由兼容模型继续（Haiku 不支持，已跳过）
- SDK 通过动态 import 按需加载，不启用 AI 时不会下载

⚠ 当前实现由浏览器直接调用 API，Key 保存在本机 LocalStorage，适合个人使用。公开部署时建议在后端实现同一接口并代为调用，避免暴露密钥。

## 测试

- `npm test`：15 个单元测试，覆盖牌库完整性（78 张、字段齐全、编号正确）、洗牌 / 切牌 / 抽牌逻辑，以及 4 种牌阵 × 6 种主题 × 15 次随机抽牌的解读生成（无 `undefined`、结构完整、结果确定）。
- 开发过程中用 Playwright 在桌面（1440×900）和手机（iPhone 13、Pixel 7 模拟）上跑通了完整流程：四种牌阵的洗牌 → 切牌 → 点选与上拖选牌 → 翻牌 → 结果页 → 牌详情 / 收藏 → 历史 / 图鉴 / 每日 / 设置，以及刷新后数据保留、每日一抽限制、主题与设置持久化、AI 无效 Key 的错误提示，控制台无报错。

## 已知限制

- 卡面是原创的风格化 SVG 线描，参考 RWS 的核心象征，并非 Pamela Colman Smith 原版插画。
- 没有音效。
- 「分享」在支持 Web Share API 的设备上调用系统分享，否则复制全文；暂不生成分享图片。
- AI 解读在开发环境中只验证了错误处理路径（沙盒无法访问 api.anthropic.com），尚未用真实 Key 端到端验证。
- 构建产物中字体文件较多（Noto Serif SC 按 Unicode 区段拆分），浏览器只会按需下载页面用到的少数分片。
